# Help and employee profile improvements

The authenticated interface now includes a contextual help panel with English, Sinhala and Tamil text. The selected help language is retained in the browser for the next page.

Employee profile capture now includes:

- service file number;
- professional registration number and expiry date;
- preferred help language;
- clear guidance that registration expiry dates drive reminders.

Lifecycle-event and document submissions redirect to the employee’s Employee 360 profile after saving. The profile form’s Back and Cancel actions return to the employee directory. Existing increment forms continue to return to the employee’s increment history.
