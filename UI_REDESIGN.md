# UI clarity and motion pass

The interface now uses progressive disclosure and calm motion:

- help content is collapsed until requested and remains available in English, Sinhala and Tamil;
- navigation sections collapse automatically when they are not the active section and remember the user’s choice;
- page content and cards use short, low-distance entrance transitions;
- buttons, navigation and summaries have visible hover/focus feedback;
- `prefers-reduced-motion` disables animation and transition effects;
- dense content remains in existing cards and tables, preserving familiar workflows while reducing visual noise.
