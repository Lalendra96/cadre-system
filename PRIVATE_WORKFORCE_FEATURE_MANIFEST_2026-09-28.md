# Private Workforce / GP Feature Manifest

- Roster (existing overlay, styling aligned)
- Attendance: manual / biometric / QR / import-ready records, corrections table
- Leave: configurable types, balances, carry-forward, half-day requests, approvals
- Overtime: roster/attendance links, configurable multiplier, approval, payroll flag
- Contracts: permanent, probation, fixed-term, part-time, hourly, locum, visiting, sessional
- Payroll: effective-dated statutory profile, adjustments, OT/locum integration, locked finalized runs
- Employee Self-Service: personal roster, attendance, leave and finalized payslip summaries
- Locum / Session Payments: session, hourly, per-patient, revenue-share and hybrid methods
- Cost Centre Analytics: payroll, OT, locum and employer statutory cost aggregation
- Super Admin module feature toggles with dependency protection
- Governance: audit integration, encrypted payroll banking fields, no destructive module disablement, payroll snapshots
