# Employee Profile Handling Count Export Font Update

The PDF export for Employee Profile Handling Count Tracking was updated for better readability when viewed or printed on A4 landscape.

Updated PDF typography:
- Body text: 10px -> 12px
- Report title: 18px -> 22px
- Subtitle: 11.5px
- Metadata: 11px
- Summary labels: 9px -> 10.5px
- Summary KPI values: 16px -> 19px
- Table headers: 8px -> 9.5px
- Table body: 11px
- Footer/governance note: 8px -> 9.5px

Row padding and line-height were also increased slightly for print readability.

CSV output is unchanged because CSV files do not carry font styling.
